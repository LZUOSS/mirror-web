本站已下架 Atom 的 GitHub Releases 发行附件镜像，以及 CentOS、Deepin 和 Anaconda 的本地镜像源。

- **Atom** 已停止维护。需要历史版本的用户可前往 [Atom 的 GitHub Releases](https://github.com/atom/atom/releases) 下载。
- **CentOS** 用户可使用南京大学镜像站。使用 CentOS Stream 请参考 [CentOS Stream 换源说明](https://help.mirror.nju.edu.cn/centos-stream/)，使用历史版本请参考 [CentOS Vault 换源说明](https://help.mirror.nju.edu.cn/centos-vault/)。
- **Deepin** 用户可使用 [中国科学技术大学 Deepin 镜像](https://mirrors.ustc.edu.cn/deepin/)。
- **Anaconda** 用户可参考 [校园网联合镜像站的 Anaconda 换源说明](https://help.mirrors.cernet.edu.cn/anaconda/)。

请更新仍使用兰大镜像地址的软件源配置和下载脚本。
