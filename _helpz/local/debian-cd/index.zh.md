## 用途

Debian 官方安装 ISO 和 Live 镜像。

## 下载方法

从 [`current/`](/debian-cd/current/) 选 CPU 架构，再从该架构的 `iso-cd/` 或 `iso-dvd/` 选择安装镜像。AMD64 Live 镜像位于 [`current-live/amd64/iso-hybrid/`](/debian-cd/current-live/amd64/iso-hybrid/)。

使用与 ISO 同目录的 `SHA256SUMS` 或 `SHA512SUMS` 校验文件核对下载；签名验证方法见 Debian 官方校验说明。
