## 用途

Raspberry Pi OS 和相关设备的系统镜像。

## 下载方法

`raspios_arm64/` 等目录对应 64 位系统，`raspios_armhf/` 等目录对应 32 位系统；另有 Lite、Full 等镜像类型。按设备支持的架构、桌面需求和版本选择镜像。

可在 Raspberry Pi Imager 中选择“使用自定义镜像”，加载下载后的镜像文件写入目标存储设备。写入会覆盖所选设备上的原有内容。
