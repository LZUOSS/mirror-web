## 用途

Raspberry Pi OS 和相关设备的系统镜像。

## 下载方法

`raspios_arm64/` 系列对应 64 位系统，`raspios_armhf/` 系列对应 32 位系统。按设备架构和需求选择桌面版、Lite 或 Full，再进入该目录下的 `images/` 选择发布日期和镜像文件。

可在 Raspberry Pi Imager 中选择“使用自定义镜像”，加载下载后的镜像文件写入目标存储设备。写入会覆盖所选设备上的原有内容。
