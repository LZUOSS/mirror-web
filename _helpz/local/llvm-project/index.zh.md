<h2>LLVM Project</h2>

<p>进入对应版本，按操作系统和 CPU 架构选择 Clang+LLVM 安装包。文件名中的 aarch64 表示 ARM64，x86_64 或 X64 表示 64 位 x86。压缩包下载后解压，Windows .exe 和 macOS .pkg 等安装器按平台说明运行，最后用 clang --version 检查版本。</p><p>自行构建请下载对应版本的主源码包。本站提供 GitHub Releases 工具链文件。LLVM 的 APT 仓、独立拆分包以及仅在官网历史归档发布的旧版可从上游获取。</p><ul><li><a href="/hpc/llvm-project/">本站版本下载</a></li><li><a href="https://llvm.org/docs/GettingStarted.html">LLVM 官方构建文档</a></li><li><a href="https://releases.llvm.org/">LLVM 官方历史版本及签名公钥</a></li></ul><p>当前核定范围包括 1705 个工件、91 个版本。版本示例为 llvmorg-10.0.0, llvmorg-10.0.1, llvmorg-11.0.0, llvmorg-11.0.1。</p>
