Anaconda 软件仓库

项目简介

Anaconda 是一个用于科学计算的 Python 发行版，支持 Linux、macOS 和 Windows，包含众多常用的科学计算和数据分析软件包。Anaconda 软件仓库还包括由 Anaconda 公司维护的官方仓库，以及 conda-forge、bioconda 等社区维护的第三方频道。

注意： Anaconda 官方仓库（即 defaults，通常对应 repo.anaconda.com/pkgs）受 Anaconda 服务条款约束。根据其当前条款，员工或承包商总数超过 200 人的营利组织通常需要订阅 Business Plan；符合条件的个人、学术机构、非营利组织和研究机构等可能可以免费使用。具体适用条件可能变化，请以官方条款为准，本文不构成法律意见。

由于 Anaconda 对官方仓库的使用和镜像分发有所限制，并且商用限制条款不符合 OSI 开源定义，部分开源镜像站不提供由 Anaconda 公司维护的仓库或 Anaconda Distribution 安装包。这些镜像站仍可能提供 Miniconda 安装包，以及 conda-forge 等社区频道。请根据当前镜像站实际提供的内容选择下方配置。

Anaconda Distribution

如果当前镜像站提供 Anaconda Distribution 安装包，可以从以下地址下载。

https://mirrors.lzu.edu.cn/anaconda/archive/

安装或使用前，请确认您的用途符合上文所述的 Anaconda 服务条款。

使用方法：包含 Anaconda 官方仓库

如果当前镜像站提供 pkgs/main、pkgs/r 和 pkgs/msys2，可以使用本节配置。此配置包含受 Anaconda 服务条款约束的官方仓库；如果您只需要社区频道，请改用下一节配置。两套配置请勿同时使用。

各系统都可以通过修改用户目录下的 .condarc 文件来使用镜像站。

不同系统下的 .condarc 目录如下：

  • Linux: ${HOME}/.condarc
  • macOS: ${HOME}/.condarc
  • Windows: C:\Users\<YourUserName>\.condarc

注：

  • Windows 用户无法直接创建名为 .condarc 的文件，可先执行 conda config --set show_channel_urls yes 生成该文件之后再修改。
  • 如果您正在从某一镜像源切换到另一镜像源，请检查镜像站是否同步了您需要的频道，以及该频道是否支持您使用的平台（例如 linux-64）。
  • 以下配置只加入少量常用的第三方频道，您可以参考下方的列表添加其他频道。
channels:
  - defaults
show_channel_urls: true
default_channels:
  - https://mirrors.lzu.edu.cn/anaconda/pkgs/main
  - https://mirrors.lzu.edu.cn/anaconda/pkgs/r
  - https://mirrors.lzu.edu.cn/anaconda/pkgs/msys2
custom_channels:
  conda-forge: https://mirrors.lzu.edu.cn/anaconda/cloud
  pytorch: https://mirrors.lzu.edu.cn/anaconda/cloud

使用下列命令清除索引缓存，并安装常用包测试一下。

conda clean -i
conda create -n myenv numpyconda clean -i
conda create -n myenv numpy

使用方法：仅使用社区频道

如果当前镜像站不提供 Anaconda 官方仓库，或者您不希望使用 defaults，请使用本节配置。配置中的 nodefaults 会阻止 conda 回落到 Anaconda 官方仓库。请勿与上一节配置同时使用。

不同系统下的 .condarc 路径如下：

  • Linux: ${HOME}/.condarc
  • macOS: ${HOME}/.condarc
  • Windows: C:\Users\<YourUserName>\.condarc

Windows 用户如果无法直接创建名为 .condarc 的文件，可以先执行 conda config --set show_channel_urls yes 生成该文件，然后再修改。

channels:
  - conda-forge
  - nodefaults
show_channel_urls: true
custom_channels:
  conda-forge: https://mirrors.lzu.edu.cn/anaconda/cloud

使用下列命令清除索引缓存，并安装常用包测试配置。

conda clean -i
conda create -n myenv numpyconda clean -i
conda create -n myenv numpy

如需使用 bioconda 等其他社区频道，请先确认当前镜像站提供该频道，再参考下方的第三方源列表添加。

第三方源列表

您可以遵循上述配置文件中的格式添加第三方源（推荐），或者通过以下命令添加第三方源：

conda config --set custom_channels.auto https://mirrors.lzu.edu.cn/anaconda/cloud/

Miniconda

Miniconda 是由 Anaconda 公司提供的精简安装器，默认只安装 Python、conda 及其必要依赖，之后可以通过 conda 或 pip 安装其他软件包。

Miniconda 安装程序与 Anaconda 官方仓库需要分别看待：安装 Miniconda 不等于必须使用 Anaconda Distribution，但 Miniconda 默认配置的 defaults 会访问 Anaconda 官方仓库，并受到上文所述服务条款约束。如果只希望使用社区频道，请安装后采用「仅使用社区频道」一节的配置。

Miniconda 安装包可以到以下链接下载。

https://mirrors.lzu.edu.cn/anaconda/miniconda/

Miniforge 与 Mamba

Miniforge 是由 conda-forge 社区维护的精简发行版，默认只使用 conda-forge，并同时提供 conda 和 mamba。安装包可以从 Miniforge 官方发布页下载；部分镜像站也可能通过单独的 GitHub Release 镜像提供安装包。

Mamba 是与 conda 软件包和环境生态兼容的高性能客户端。当前 Miniforge 已经包含 Mamba，无需再选择 Mambaforge；Mambaforge 已被弃用，并已于 2025 年停止发布新版本。

使用 Mamba 时，可以通过 .condarc 中的 mirrored_channels 将 conda-forge 指向当前镜像站：

channels:
  - conda-forge
mirrored_channels:
  conda-forge:
    - https://mirrors.lzu.edu.cn/anaconda/cloud/conda-forge

可以使用以下命令检查配置是否生效：

mamba config list --json | python -c "import sys, json; info = json.loads(sys.stdin.read()); print(info['mirrored_channels']['conda-forge'])"mamba config list --json | python -c "import sys, json; info = json.loads(sys.stdin.read()); print(info['mirrored_channels']['conda-forge'])"
